Updating?

Quit KeyStow first, then run the new installer.

On Windows

The installer may show a "Windows protected your PC" prompt. If it does: choose More info, then Run anyway.

On Mac

The first launch may show a one-time "unidentified developer" prompt. If it does: right-click the KeyStow app and choose Open, or go to System Settings > Privacy & Security > Open Anyway.
