KeyStow third-party notices
===========================

KeyStow's own code is under the MIT licence: see LICENSE.txt in this folder.
Source: https://github.com/hullashoo6/keystow

The installers also contain the third-party software listed in this file. Each
part stays under its own licence. Where a package carries its licence text, it
is in the packages folder. The full texts of the common licences are in the
texts folder.

No FFmpeg (from v1.0.7)
    The speech library imports PyAV only to decode audio files, which
    KeyStow never does: it passes microphone samples. Installers from
    v1.0.7 contain a small stand-in module (KeyStow's own code, MIT) in
    place of PyAV, so no FFmpeg, x264 or x265 library is included.
    Installers up to v1.0.6 did contain them: FFmpeg under the GNU LGPL
    v2.1 or later, built with x264 and x265 under the GNU GPL; sources at
    https://github.com/PyAV-Org/pyav-ffmpeg and https://ffmpeg.org/.
