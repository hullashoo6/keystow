# Security

Please report a security problem in KeyStow by email to hullashoo6@gmail.com, not in a public issue. Say which version you used (it is at the top of the tray menu) and how to reproduce the problem.

Fixes are made to the latest release only.

The installers are not code-signed. Get them only through the KeyStow website, https://keystow.pages.dev/. From v1.0.7 on, each release's notes list the SHA-256 of both installers, if you want to check a file.
