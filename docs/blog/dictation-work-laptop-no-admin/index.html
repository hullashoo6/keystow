Dictation on a Locked-Down Work Laptop: Your Honest Options

November 24, 2026 · KeyStow · All articles

The locked-down reality

Many work laptops block new software: no admin rights, installs only through an IT ticket, sometimes an approved-software list. If that is your machine, the honest starting point is not "which app is best" but "what am I allowed to run."

Your realistic options

  • Use what is already there. Windows has built-in voice typing and macOS has built-in Dictation. They need no install and no approval, and for occasional short text they are genuinely fine. Check whether they work without internet on your setup before relying on them in a dead zone.
  • Ask IT, and make it easy to say yes. A one-paragraph request works better than a link dump: what the tool does, why you need it, what it costs, and where its code or security notes can be reviewed. Tools with inspectable source code and no cloud connection give a security team far less to object to.
  • Respect the personal-device line. Dictating work documents into a personal phone feels like a shortcut and can violate company policy or client agreements. Check the rules before going around the laptop.
  • Do not sneak it in. Portable apps and workarounds can breach policy even when the software itself is harmless. A rejected request is a delay; a policy breach is a conversation nobody wants.

If the answer is no

Then the built-in tools are your dictation, and that is acceptable. A policy-compliant tool you may use beats a better tool you may not.
