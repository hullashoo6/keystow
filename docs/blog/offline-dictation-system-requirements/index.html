How Much Disk Space and RAM Does Offline Dictation Need?

November 24, 2026 · KeyStow · All articles

The trade that offline makes

Cloud dictation borrows someone else's computer, so the app itself is tiny. Offline dictation brings the speech model home, and models take space. The question is how much, and whether an ordinary laptop notices.

Disk space: the model is most of it

A small speech model runs to a few hundred megabytes; larger, more accurate models run higher. The app around it is minor by comparison. KeyStow is a useful worked example: with the default speech model bundled in, the installed app takes about 385 MB on Windows and about 536 MB on Mac (measured on v1.0.8; the downloads themselves are about 195 MB and 267 MB). That is roughly a short video's worth of disk, once, instead of a per-month subscription fee.

Memory: it matters while you dictate

While you hold the key, the model is loaded and working. Smaller models need less memory and answer faster; larger models need more of both. For everyday dictation on a machine that already runs a browser with a dozen tabs, the default model is not the thing that will slow you down. Close the twenty-tab browser session before blaming the dictation app.

Practical guidance

  • Check the stated install size before downloading, especially on a nearly full drive.
  • Start with the default model. Step up to a larger one only if you hear accuracy problems the small one makes.
  • Updates replace, not pile up. A well-built installer swaps the old version rather than adding beside it, so the footprint stays flat over time.

How KeyStow fits

KeyStow is an offline voice dictation app for Windows and Apple Silicon Mac. The install is about 385 MB on Windows and about 536 MB on Mac with the default model bundled, so dictation works from first launch with no download, and larger models are available as options. Hold Right Ctrl on Windows (Right Option on a Mac), speak, release, and text is pasted where the cursor is. Your voice is processed privately on your own computer and never sent to the cloud, and dictation works without internet too. KeyStow does not keep an audio recording or transcript history. It costs $5 once, with no subscription and no account, and the source code is open under the MIT license.
