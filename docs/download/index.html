Updating?

On Windows, just run the new installer: it closes KeyStow for you. On a Mac, quit KeyStow first, then replace the app in Applications.

On Windows

The installer may show a "Windows protected your PC" prompt. If it does: choose More info, then Run anyway.

On Mac

Open the disk image and drag KeyStow into Applications. macOS asks you to confirm KeyStow once, the first time: the disk image includes Open KeyStow the first time with the steps. Then allow the microphone and Accessibility when KeyStow asks.
